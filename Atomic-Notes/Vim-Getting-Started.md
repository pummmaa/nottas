# Table Of Contents

## Vim Modes
To enter these mode press the letter the mode is represented by
1. Normal (n)
2. Insert (i)
3. Visual (v)
4. Command (:)

## Advancy Commands (non modifier)
- *w* to move *one word* at the time to the right (forward)
- *b* to move *one word* at the time to the left (back)

## Advancy Commands (using modifier "SHIFT")
- *Shift+A* to move at the beggining of the line
- *Shift+I* to move at the end of the line
